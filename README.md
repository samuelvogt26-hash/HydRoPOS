# HydRoPOS
## 🛒 HydRo POS v1.0 – Deine eigene Kassen-App, kostenlos

HydRo POS ist ein Kassensystem (Point of Sale) für kleine Läden, Märkte und Stände. Keine monatlichen Gebühren, keine Anmeldung, keine Cloud: Du lädst die Exe herunter, startest sie und kannst direkt verkaufen. Alle Daten bleiben bei dir.

### ✨ Das kann HydRo POS

**Schöner Start**
- Ladescreen mit Einkaufswagen, der die Ladelinie entlangfährt
- Beim ersten Start: Einkaufswagen nach rechts wischen zum Entsperren (per Maus oder Touch)
- Einfache Einrichtung: Name, Telefonnummer, Storename, Scanner oder Kamera
- Danach: Ladescreen mit deinem Storenamen und Ziffernblock für die PIN

**Verkaufsmodus**
- Produkte per Barcode-Scanner, Kamera, Suche oder Antippen hinzufügen
- Warenkorb mit Mengen ändern, Zwischensumme und Gesamtpreis
- Rabatt- und Gutscheincodes einlösen, der Preis sinkt automatisch
- Bezahlen per Gutschein, Bar (mit Rückgeld-Rechner) oder Karte (z. B. SumUp)

**Developer-Modus**
- Produkte mit Bild, Preis, Einkaufspreis, Barcode und Bestand anlegen, ändern und löschen
- Link zu einem kostenlosen Barcode-Generator

**Rabattcodes**
- Eigene Gutscheine mit Prozent-Rabatt und Code erstellen (z. B. 25 % mit 260414)
- Mehrfach einlösbar: z. B. 100 Stück mit demselben Code
- Vorlageblatt mit deinem Storenamen zur Vorschau
- Jederzeit wieder löschbar

**Gewinn / Verlust**
- Umsatz, Wareneinsatz und Gewinn für heute oder insgesamt
- Liste aller Verkäufe und der verkauften Produkte

**Einstellungen**
- Speicherordner frei wählbar
- Deine Infos jederzeit bearbeiten
- Eigenes App-Logo und Boot-Logo (PNG)
- Scanner oder Kamera auswählen, Kartengerät festlegen
- Design: Dunkel, Grau oder Hell
- PIN beim Start festlegen
- Sicher abmelden, deine Daten bleiben im Ordner erhalten

### 📥 Installation
1. `HydRoPOS.exe` herunterladen
2. In einen eigenen Ordner legen (dort werden deine Daten gespeichert)
3. Doppelklick zum Starten, Python wird nicht benötigt

### ⚠️ Hinweis zu Windows
Beim ersten Start zeigt Windows evtl. „Der Computer wurde durch Windows geschützt". Die Exe ist nicht signiert. Klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**.
